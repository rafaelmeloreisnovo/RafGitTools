# RAFAELIA Traceability Matrix

Matriz inicial de rastreabilidade das fórmulas, variáveis e campos RAFAELIA. A matriz foi derivada de quatro entradas: o prompt de solicitação desta OS, `_incoming/README.md`, `Livro/RAFAELIA_MATH_FORMULAS.md` quando presente, e arquivos sob `rafaelia/` em até 5 níveis de profundidade.

> Observação de escopo: `Livro/RAFAELIA_MATH_FORMULAS.md` não existe no estado atual do repositório analisado. Linhas com evidência "prompt desta OS" representam requisitos conceituais fornecidos pelo usuário e ainda não possuem arquivo-fonte versionado além desta matriz.

## Critérios de status

| Status | Critério usado nesta matriz |
|---|---|
| conceitual | Existe apenas no prompt, em narrativa técnica, ou como intenção sem contrato verificável. |
| especificado | Existe como constante, campo, API, documentação técnica ou requisito com formato definido. |
| prototipado | Existe protótipo executável/demonstrável, mas sem cobertura suficiente para produção. |
| implementado | Existe implementação no repositório com API/código identificável. |
| testado | Existe teste automatizado ou validação programática direta no repositório. |

## Lacunas imediatas

1. Versionar ou criar `Livro/RAFAELIA_MATH_FORMULAS.md` se ele for fonte canônica futura.
2. Separar fórmulas matemáticas comprovadas de metáforas conceituais em documentação distinta.
3. Adicionar vetores oficiais para FNV-1a 64-bit e CRC32C.
4. Criar schema formal para `tag14`, `rafbit10`, campos matriciais e campos RAFAELIA.
5. Criar validação Android/JNI antes de qualquer afirmação de entrega full-stack mobile.
6. Executar validação ARM32/Termux em ambiente real antes de declarar suporte operacional além de runtime/toolchain.
