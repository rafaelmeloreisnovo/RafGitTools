# Single Session Subtokenization v1

The complete conversation is represented as one session capsule with sixteen
ordered atomic subtokens.

```text
one capsule != one undifferentiated claim
```

The capsule preserves negation, modality, conditions, units, source authority
and claim gates. It does not copy the raw private transcript into every
repository.

```text
RLL         physics and scientific boundaries
RafPolimata finite permutations and backend routing
RafGitTools capsule, provenance and deterministic seal
Mapa        pointer-only relations
papers      optional editorial projection
```

The excluded topic is represented only by an exclusion rule and is not
materialized as session content.

GPT contextual transformation is not physical plasma dissipation, and token
prediction is not demonstrated volition.

```text
claim_allowed=false
private_payload_copied=false
automatic_cross_repo_write=false
automatic_merge=false
```
