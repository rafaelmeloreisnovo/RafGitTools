# RafGitTools — Observer Conduct Correction Router V1

This router makes the session's `conduta` operational without equating observation with permission to mutate code.

- `ATTENTION / THINK / PERMUTE / ANOMALY / DELTA / EMPTY_OR_GAP` → observation only.
- `UNCERTAIN / UNKNOWN / OPPORTUNITY / CONTRADICTION / ANOMALY` epistemic states → review hold.
- `REFUSE` → preserve provenance, no mutation.
- `BUG / ERROR / UPDATE / EDIT / ACT` → correction candidate, but only after exact target, SHA, deterministic reproducer, root-cause evidence, bounded patch, tests and rollback.

`HOTFIX_ELIGIBLE_BOUNDED != MERGE_ALLOWED`.
