## Responsabilidade deste repositório

Dentro da IEA, o RafGitTools preserva a autoridade de operação entre humano, Git, GitHub, branches, PRs e evidências.

```text
intenção
→ autoridade semântica
→ autoridade executiva
→ operação limitada
→ revisão
→ receipt/rollback
```

Nenhuma semelhança de nome, índice ou significado autoriza execução automática. A origem, a branch, o commit, o escopo da mudança, a identidade do responsável e a possibilidade de reversão devem permanecer verificáveis.

## Fronteiras preservadas

```text
interpretação ≠ permissão para executar
referência normativa ≠ conformidade
PR aberta ≠ merge autorizado
merge ≠ runtime PASS
fila offline ≠ sincronização concluída
```
