Como verificar

  1. Calcule SHA-256 do APK recebido.
  2. Compare com signed_apk_sha256 do receipt.
  3. Leia o certificado de assinatura do APK com uma ferramenta Android compatível.
  4. Compare com certificate_sha256.
  5. Confira o source_sha no repositório de origem.

Fronteira

O certificado prova a chave que assinou o APK. O receipt liga essa assinatura ao SHA do artefato e ao source SHA. Nenhum desses fatos, isoladamente, prova toda alegação científica ou funcional do aplicativo.
